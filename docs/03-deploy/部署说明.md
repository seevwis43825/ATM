# 部署说明

> 【交付物③的一部分】负责人：B

## 一、部署目标

让评委通过一个公网链接直接体验产品，无需安装任何东西。

## 二、部署架构

| 部分 | 平台 | 说明 |
|---|---|---|
| 前端 | Vercel | 免费，推送自动部署 |
| 后端 | Railway / Render | 免费额度够演示用 |

## 三、前端部署（Vercel）

```bash
cd apps/web
npm install -g vercel
vercel login
vercel --prod
```

在 Vercel 项目设置里配置环境变量：
```
VITE_API_BASE_URL=https://你的后端地址
```

## 四、后端部署（Railway）

1. 登录 railway.app，新建项目，选择 Deploy from GitHub repo
2. 选择 `ai-banking` 仓库，Root Directory 设为 `apps/api`
3. 配置环境变量（同 `.env.example`）
4. 平台会自动执行 `npm install && npm start`

## 五、本地部署验证

```bash
# 构建
cd apps/web && npm run build
cd ../api && npm run build

# 启动
npm start
```

## 六、验收标准

- [ ] 公网链接可访问，手机浏览器打开正常
- [ ] 能完成一次完整对话（输入"给张三转500"得到确认卡片）
- [ ] `GET /api/health` 返回 `{"status":"ok"}`
- [ ] 冷启动时间 < 30 秒（免费平台会休眠，演示前先唤醒）

## 七、演示前检查（重要）

免费平台会在无人访问时休眠，评委点开要等 30 秒以上，非常影响印象。

**对策**：答辩前 15 分钟手动访问一次唤醒服务，或升级到付费计划。

## 八、回滚方案

如果线上出问题，立即切回本地演示：

```bash
bash scripts/dev.sh
# 用 localhost:5173 演示
```

务必备一份录屏作为最终兜底。
