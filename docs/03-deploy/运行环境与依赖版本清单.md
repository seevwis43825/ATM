## 一、运行时环境

| 组件 | 要求版本 | 本项目实际使用 | 说明 |
|---|---|---|---|
| **Node.js** | **≥ 20 LTS** | **22.22.2** | 前后端统一运行时，`package.json` 中 `engines.node` 已声明 |
| **npm** | ≥ 10 | **10.9.7** | 随 Node.js 22 一同安装 |
| **操作系统** | Windows 10+ / macOS 12+ / Linux | Windows 11 专业版（Build 26200，64 位） | 跨平台，无平台专属代码 |
| **CPU 架构** | x86_64 / ARM64 | x86_64 | 无原生编译依赖，任意架构可用 |
| **Git** | ≥ 2.30 | **2.55.0.windows.3** | 仅克隆仓库需要 |

### 关于 Python

**本系统运行不需要 Python。** 前后端均为 Node.js / TypeScript 实现，无任何 Python 依赖，项目内不含 `.py` 文件。

唯一涉及 Python 的地方是开发辅助脚本 `scripts/demo.sh` —— 它用 `python -c` 把接口返回的 JSON 格式化后打印，方便录视频前核对。该脚本**不属于系统运行链路**，不执行也不影响任何功能。

如需运行该脚本，本机环境为 Python 3.13.14，仅使用标准库 `json`，无需安装第三方包。

## 四、不依赖的外部服务

以下项目**本系统均未使用**，这是为了保证评委无需任何配置即可运行：

| 项目 | 状态 | 说明 |
|---|---|---|
| 数据库 | ❌ 不需要 | 使用 JSON 文件作为数据源（`banking-core/mock-data/`） |
| Redis / 消息队列 | ❌ 不需要 | 会话与待确认操作存于进程内存 |
| 大模型 API | ⭕ 可选 | `MOCK_MODE=true`（默认）时使用内置规则引擎，无需 API Key |
| 外部网络请求 | ❌ 不需要 | 全部逻辑本地完成，断网可运行 |
| Docker | ❌ 不需要 | 直接 `npm install` 即可 |

> **设计意图**：把"能跑起来"的门槛降到零。任何人 clone 仓库后执行一条命令即可看到完整功能，不因缺少密钥或服务而卡住。

## 九、复现步骤（评委可照此验证）

```bash
# 1. 环境要求：Node.js ≥ 20（推荐 22 LTS）
node --version

# 2. 获取代码
git clone https://github.com/seevwis43825/ATM.git
cd ATM

# 3. 一键启动（自动安装依赖 + 同时启动前后端）
bash scripts/dev.sh

# 4. 浏览器访问
#    http://localhost:5173
```

### 验证依赖安装是否正确

```bash
npm test        # 预期输出：通过 44 项，失败 0 项
```

### 验证依赖版本是否与本文档一致

```bash
npm --prefix apps/api ls --depth=0
npm --prefix apps/web ls --depth=0
```

> 由于 `package.json` 使用 `^` 语义化版本范围，重新安装时小版本号可能略高于本文档记录（例如 `express` 可能装到 4.22.x 的更新版本）。**主版本号一致即兼容**，不影响功能。

## 十、CI 环境

GitHub Actions 工作流（`.github/workflows/ci.yml`）使用：

| 项目 | 版本 |
|---|---|
| 运行环境 | `ubuntu-latest` |
