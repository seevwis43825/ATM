# 运行环境与依赖版本清单（当前 .NET 主线）

> 【交付物③ 部署材料】组成部分
> 版本事实以项目文件、CI 配置和工具清单为准，不以某台开发机的精确补丁版本为全队约束。

## 一、结论

当前系统由两个 .NET 进程组成：

| 进程 | 默认端口 | 目标框架 | 说明 |
|---|---:|---|---|
| `MockBank.Api` | 5200 | `net8.0` | 模拟银行核心系统 |
| `BankingAgent.Host` | 5243 | `net8.0` | Agent API、SQLite 与内置 `wwwroot` 控制台 |

本地默认使用 SQLite，不需要安装外部数据库。控制台随 Host 提供，不需要 Node.js 或独立前端服务。

## 二、必需环境

| 项目 | 要求 | 用途 | 版本依据 |
|---|---|---|---|
| 操作系统 | Windows / macOS / Linux | 开发与运行 | ASP.NET Core 跨平台运行；CI 使用 Linux |
| .NET SDK | 9.0.200+ | 读取并编译 `.slnx` | `src/BankingAgent.slnx`；CI 同时安装 9.0.x |
| .NET Runtime | 8.0.x | 运行两个 `net8.0` 进程 | 各 `*.csproj` 的 `TargetFramework` |
| .NET 8 Targeting Pack | 8.0.x | 编译 `net8.0` 项目 | 各 `*.csproj`；安装 .NET 8 SDK 可一并提供 |
| 四个插件 DLL | Release 构建产物 | 宿主业务能力 | `BankingAgent.Host.csproj` 的 `PluginArtifact` |

本机已验证环境示例：

- .NET SDK 9.0.305
- .NET Runtime 8.0.20

这是验证记录，不要求其他机器锁定到完全相同的补丁版本。满足 SDK 9.0.200+ 且具备 .NET 8 Runtime/Targeting Pack 即可。

检查命令：

```powershell
dotnet --version
dotnet --list-sdks
dotnet --list-runtimes
```

## 三、必需的 Release 插件产物

完整解决方案 Release 编译后，目录
`src/src/BankingAgent.Host/bin/Release/net8.0/plugins/` 必须包含：

1. `BankingAgent.Plugin.Transfer.dll`
2. `BankingAgent.Plugin.BillAnalysis.dll`
3. `BankingAgent.Plugin.CardManagement.dll`
4. `BankingAgent.Plugin.Wealth.dll`

检查命令：

```powershell
dotnet build src/BankingAgent.slnx -c Release

$pluginDir = "src/src/BankingAgent.Host/bin/Release/net8.0/plugins"
Get-ChildItem $pluginDir -Filter "BankingAgent.Plugin.*.dll"
```

插件复制依赖构建配置。Release 编译后必须用 `-c Release` 启动，不能用默认 Debug 启动。

## 五、EF Core CLI

`src/.config/dotnet-tools.json` 将 `dotnet-ef` 锁定为 8.0.10，并关闭版本滚动：

```powershell
Push-Location src
dotnet tool restore
dotnet ef --version
Pop-Location
```

不要全局安装其他版本替代仓库工具清单。

## 六、可选项

| 项目 | 是否必需 | 当前定位 |
|---|---|---|
| Git | 获取代码时需要 | 直接使用源码包运行时可不需要 |
| IDE | 否 | Visual Studio、Rider、VS Code、Cursor 均可 |
| `Ai__ApiKey` | 否 | 增强意图识别；默认规则表可独立运行 |
| PostgreSQL | 否 | 生产化演进选项；本地默认 SQLite |
| SQL Server | 否 | Provider 已引用，不是默认运行路径 |

可选 AI Key：

```powershell
$env:Ai__ApiKey = "sk-xxx"
dotnet run --project src/src/BankingAgent.Host -c Release
```

可选 PostgreSQL 使用 `Database__Provider`、`Database__ConnectionString` 和 `Database__InitMode` 配置。它还需要数据库实例、迁移、备份、密钥和网络策略，不能仅凭 Provider 包认定生产部署已完成。

## 七、本地默认不需要

| 项目 | 状态 | 原因 |
|---|---|---|
| 外部数据库 | 不需要 | 默认使用 SQLite 文件 |
| Docker / Docker Desktop | 不需要 | 当前没有本地运行所需容器 |
| Node.js / npm | 不需要 | 控制台已内置在 Host 的 `wwwroot` |
| Python / pip | 不需要 | 当前主线没有 Python 运行进程 |
| Redis | 不需要 | 当前运行链路未依赖 Redis |
| Kafka | 不需要 | 当前使用进程内事件总线 |
| AI Key | 不需要 | 默认规则表可完成意图路由 |
| 独立前端服务器 | 不需要 | Host 在 5243 提供控制台 |

## 八、默认配置与数据

Host 的 `appsettings.json` 默认配置：

| 配置 | 默认值 | 说明 |
|---|---|---|
| `Database:Provider` | `Sqlite` | 本地默认 Provider |
| `Database:ConnectionString` | `Data Source=bankingagent.db` | 业务库文件 |
| `Database:InitMode` | `EnsureCreated` | 本地启动时建表 |
| `CoreBank:BaseUrl` | `http://localhost:5200` | MockBank 地址 |
| `Ai:ApiKey` | 空 | 走规则表，不阻断启动 |

宿主还会维护独立审计库与审计日志。停止服务前不要移动或删除正在使用的 SQLite 文件。

## 九、CI 版本依据

`.github/workflows/ci.yml` 是持续验证环境的事实源：

| 项目 | CI 配置 |
|---|---|
| 操作系统 | `ubuntu-latest` |
| SDK | 同时安装 `8.0.x` 与 `9.0.x` |
| 编译 | `dotnet build src/BankingAgent.slnx -c Release` |
| 测试 | Release 单元测试、端到端测试、并发压测 |
| 插件 | 显式检查四个 Release DLL |
| EF 工具 | 从 `src/.config/dotnet-tools.json` 恢复 |

SDK 9 用于 `.slnx` 与编译入口；SDK/Runtime 8 提供 `net8.0` 运行与工具兼容环境。二者职责不同，不能只安装 SDK 9 后假定系统一定具备 .NET 8 Runtime。

## 十、复现与验收

从仓库根目录执行：

```powershell
dotnet restore src/BankingAgent.slnx
dotnet build src/BankingAgent.slnx -c Release
```

两个终端分别启动：

```powershell
dotnet run --project src/mock-bank/MockBank.Api -c Release
```

```powershell
dotnet run --project src/src/BankingAgent.Host -c Release
```

验收：

```powershell
Invoke-RestMethod http://localhost:5200/health
Invoke-RestMethod http://localhost:5243/health
```

最后打开 <http://localhost:5243>，确认内置控制台可登录、对话和执行人工确认流程。

## 十一、公网与生产状态

仓库当前没有现成 Dockerfile、IaC、云平台部署清单或已验证公网地址。PostgreSQL 和 AI 接入只能标记为可选增强/生产化演进，不能视为已交付公网部署方案。

## 十二、版本事实源

发生冲突时按以下顺序判断：

1. `src/**/*.csproj`：目标框架与 NuGet 直接依赖
2. `.github/workflows/ci.yml`：持续验证的 SDK、系统与命令
3. `src/.config/dotnet-tools.json`：`dotnet-ef` 锁定版本
4. `src/src/BankingAgent.Host/appsettings.json`：默认运行配置
5. 根 `README.md` 与当前部署文档：操作入口与说明
