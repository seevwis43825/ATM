## 1. C4 模型说明

C4 模型由 Simon Brown 提出，是一种"自上而下"分层描述软件架构的方法。

- **Level 1 - Context**：系统与外部参与者的关系
- **Level 2 - Containers**：系统内的可独立部署单元
- **Level 3 - Components**：每个 Container 内部的关键组件
- **Level 4 - Code**：具体实现（一般不画）

本文为 **Level 1**。

## 3. 外部参与者清单

| 参与者 | 类型 | 描述 | 与系统交互 |
|--------|------|------|-----------|
| **客户（个人/企业/VIP）** | 人员 | 主要使用者 | 通过 IM/APP/语音与 Agent 对话、确认敏感操作 |
| **银行客户经理** | 人员 | VIP 客户专属 | 高净值场景下接收 Agent 工单、确认异常 |
| **合规审计人员** | 人员 | 内部审计 | 调阅 Audit 日志、生成合规报告 |
| **运维工程师** | 人员 | 维护系统 | 监控、部署、事故响应 |
| **客服坐席** | 人员 | 兜底服务 | 接收 Agent 转人工、解决复杂投诉 |
| **核心银行系统（CBS）** | 系统 | 内部 | 提供账户、余额、转账、卡片底层 API |
| **支付清算通道**（银联/网联/超网） | 系统 | 外部 | 跨行转账、支付清算 |
| **LLM 提供方**（Qwen/DeepSeek/OpenAI） | 系统 | 外部 | 提供大模型推理 |
| **第三方商家**（美团/京东/支付宝） | 系统 | 外部 | 跨场景联动（如订阅管理、订蛋糕/鲜花） |
| **监管报送系统**（人行/金监总局） | 系统 | 外部 | 接收反洗钱、可疑交易报告 |
| **身份认证服务**（短信/生物识别） | 系统 | 外部 | 用户身份验证 |
| **KMS/HSM** | 系统 | 外部 | 密钥管理、敏感数据加解密 |

## 4. 关键交互场景

### 场景 1：用户执行转账

```
用户 ──"转500给小李"──> [AI Banking Agent System]
                            │
                            ├──> LLM 提供方（理解意图）
                            ├──> 核心银行系统（执行转账）
                            ├──> 支付清算通道（跨行）
                            └──> 监管报送系统（大额/可疑）
                            │
用户 <──"转账成功"────
```

### 场景 2：跨场景联动（订蛋糕）

```
用户 ──"我爱人生日下周五"──> [AI Banking Agent System]
                              │
                              ├──> LLM 提供方（理解 + 记忆）
                              ├──> Memory Agent（记录日期）
                              ├──> Cross-Scenario Coordinator（编排任务）
                              ├──> Transfer Agent（锁定1000元活期）
                              └──> 第三方商家（生日前2天下单）
                              │
用户 <──"已为您预订好蛋糕和鲜花"──
```

### 场景 3：客服兜底

```
用户 ──"我要投诉"──> [AI Banking Agent System]
                       │
                       ├──> Conversation Agent（识别情绪）
                       ├──> 转人工（无法处理时）
                       │
                       └──> 客服坐席 ──> 处理 ──> 用户
```

## 5. 数据流概要

| 数据类型 | 来源 | 去向 | 备注 |
|---------|------|------|------|
| 用户对话 | 用户 | 系统 → LLM | 仅当前会话保留上下文 |
| 交易指令 | 系统 | CBS | 内部 API 调用 |
| 决策日志 | 系统内部 | Audit 模块 | 不可篡改、合规留存 |
| 反洗钱报告 | 系统 | 监管 | 自动生成、加密传输 |
| 用户画像 | Memory Agent | 同模块 | 不出域、不出环境 |
| 商家订单 | Cross-Scenario | 第三方商家 | 凭证加密存储 |
