## 6. 每日同步机制

### 6.1 Daily Standup（每日 10:00）

**形式**：视频会议，15 分钟，固定时间

**每人发言模板**（1 分钟）：
```
1. 昨天完成：
   - [具体 PR / 任务]
2. 今天计划：
   - [具体 PR / 任务]
3. 卡点：
   - [如有，需要谁帮助]
```

### 6.2 异步优先

**何时开会**：设计评审 / 集成 / 复盘 / 紧急事故
**何时不开会**：进度同步（看看板）/ 答疑（异步讨论）/ 信息通告（写文档）

## 11. 这个示例教会我们什么

✅ **5 人协同的核心**：
1. **明确分工** — 每个角色有自己的「主场」和「硬规则」
2. **每天同步** — Daily Standup + 异步优先
3. **定期同步** — 5 个关键会议贯穿 10 天
4. **持续反馈** — 每个 PR 都有 Review，每个决策都有 ADR
6. **共同责任** — 发布成功 5 人共享，事故 5 人共担

❌ **常见误区**：
1. ❌ 5 人一起写同一段代码 → 各写各模块，通过接口契约对接
2. ❌ 架构师高高在上 → 架构师是 Reviewer + Mentor，不是命令者
3. ❌ 合规只在末尾 → 合规从 Day 1 开始（PIA）
4. ❌ 平台只是运维 → 平台参与每个 PR 的 CI/CD 设计
