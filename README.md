# AI Banking Agent

> 人工智能赛道参赛作品：用自然语言对话完成银行业务的 Agent 系统。

---

## 一句话介绍

用户打开网页，像聊天一样说"给张三转 500 块，备注房租"，Agent 理解意图、自主规划、调用银行工具、生成确认卡片，用户点头即完成。账单分析、理财申购、卡片管理同理。

## 快速开始（每个组员 clone 后照做）

```bash
git clone https://github.com/seevwis43825/ATM.git
cd ATM

# 一条命令搞定：自动装依赖 + 同时启动前后端
bash scripts/dev.sh
```

浏览器打开 **http://localhost:5173**，看到聊天界面即成功。

> **没有 AI key 也能跑。** 项目默认 `MOCK_MODE=true`，意图识别走规则引擎，所有业务数据来自 Mock 文件。任何人 clone 下来都能立即看到完整流程，不用等别人配好环境。

### 手动启动（如果你想分开跑）

```bash
npm run install:all     # 安装前后端依赖
cd apps/api && npm run dev    # 后端 3001
cd apps/web && npm run dev    # 前端 5173（另开终端）
```

### 验证功能

```bash
npm test                # 34 项冒烟测试，覆盖六大场景 + Agent 主链路
```

**已实现的关键设计：**

- Agent 无执行权 —— 所有资金操作生成确认卡片，用户点头才执行
- 三级风险分级 —— 每次操作返回 `riskLevel`，高风险强制二次确认
- 全链路审计 —— 每次调用生成 `auditId`，`GET /api/audit` 可查
- 可解释异常识别 —— 三条规则（金额离群 / 深夜大额 / 首次跨境）
- 硬性理财风控 —— 只推荐 ≤ 用户风险等级的产品
- **多轮对话上下文** —— 支持指代消解，见下方示例
- 未知 UI 类型兜底 —— 前端永不白屏

### 多轮对话示例（这是"真 Agent"和"命令解析器"的分界线）

| 第 1 轮 | 第 2 轮 | Agent 的表现 |
|---|---|---|
| 给张三转500块 | **那再转200** | 自动补全收款人为张三 |
| 我有5万闲钱，想做个稳健点的理财 | **就买第一个** | 选中第 1 款产品，并复用 5 万金额 |
| 我有哪些自动扣费 | **取消那个** | 定位到即将扣费的那笔订阅 |
| 我有哪些银行卡 | **把第一张卡锁了** | 锁定第 1 张卡 |

Agent 会把"记住了什么"暴露出来，便于验证和答辩演示：

```bash
curl http://localhost:3001/api/session/<会话ID>
```

| 方法 | 路径 | 用途 |

## 协作铁律（违反 = 全队返工）

1. **不直接推 main。** 所有改动走 `feature/xxx` 分支 + Pull Request。
2. **契约优先。** 要改 `banking-core/contracts/` 里的任何东西，先在群里说，改完更新版本号。
3. **Mock 先行。** 每个人第一天就把自己场景的假数据跑通，不依赖别人。
4. **每天 commit。** 哪怕只改了注释。项目经理（A）每天睡前看一次贡献图。
5. **接口不等人。** 如果 B 的工具没写完，A 用 Mock 版占位，绝不阻塞集成。
6. **文档跟代码同分支提交。** 不要最后一周才补文档——那是灾难。
